# Changelog

Todos los cambios notables de este proyecto se documentan en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/)
y este proyecto adhiere a [Versionamiento Semántico](https://semver.org/lang/es/).

## [No publicado]

### Corregido
- Se corrigió un error de compilación en `GestionRenovacionComponent` (flujo de corrección): se enviaba `documentoCorregido` (metadatos `DocumentoCargado`) a `CorreccionService.registrar`, que espera el `File` real en el campo `archivo`. Ahora se envía `archivo: this.archivo()!`.

### Agregado
- Se habilitó **"Contratos" para cuentas en estado prospecto**: el módulo pasó de `MODULOS_RESTRINGIDOS` a `MODULOS_PROSPECTO` en `cuenta.model.ts` (sin candado) y se agregó el acceso "Contratos" al `ACCESOS_SIDEBAR`, alineado con el backend que ahora permite la generación de contratos a prospectos.
- Se agregó la **gestión de corrección de documentos desde Seguimiento**: en el `Detalle_Solicitud`, cuando la solicitud está en estado `observada`, aparece el botón "Actualizar documentos" que navega al flujo de Corrección (`/app/correccion?referencia=…`) con la referencia precargada. `CorreccionComponent` ahora lee la `referencia` del query param.

### Cambiado
- Se alineó `CorreccionService` al contrato real del backend: `POST /api/v1/correcciones` se envía como `multipart/form-data` (campos `referencia`, `archivo` real y `observaciones`) en lugar de JSON, y se mapea la respuesta (`tiempoEstimadoDias`) a `tiempoEstimadoRevision`. `CorreccionComponent` conserva el `File` real del documento corregido para el envío. Verificado end-to-end: corrección propia `201`, corrección de referencia ajena `404` (anti-BOLA).
